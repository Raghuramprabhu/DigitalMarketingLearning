# Fable edition

A second telling of this site, living entirely in `/fable/`. Nothing outside this folder is used or changed,
with one exception: the Calm Feed reads the live `../feed/data/items.json` so it stays fresh.

- `index.html` — the home sky (hand-written).
- `core/fable.css`, `core/fable.js` — design system and experience engine: sky, iris transitions,
  journey mode (one scene at a time), sparks, Ember, focus beam, calm motion.
- `tools/sync.py` — re-copies the classic sections into `/fable/` and gives each page its Fable shell.
  Run `python3 fable/tools/sync.py` from the repo root after the classic pages change.
  A new classic page needs one line in `PAGES` there, and a door in `WORLDS` in `core/fable.js`.
- Everything else (`chapters/`, `chess/`, `computing/`, `git/`, `math/`, `piano/`, `feed/`, `assets/`)
  is generated by `sync.py`. Edit the classic page, then re-run it.
